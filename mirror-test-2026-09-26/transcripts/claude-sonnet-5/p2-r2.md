# Ring — 5-Turn Playthrough

**Setup:** marker at cell 0, visited = {0}. Amber: {1,2,3,5}. Blue: {1,3,4,6}.

---

MOVE 1: Amber plays 3 -> cell 3
STATE 1: cell=3 visited=0,3 score Amber=3, Blue=0

*Reasoning:* First move of the game is always clockwise (Rule 2 override), so no sum check needed. From cell 0, playing 3 clockwise lands on cell 3 (0→1→2→3). Cell 3 is unvisited, so it's legal. Amber scores 3.

---

MOVE 2: Blue plays 4 -> cell 7
STATE 2: cell=7 visited=0,3,7 score Amber=3, Blue=7

*Reasoning:* Previous tile was 3 (Amber's). Sum = 3+4 = 7, not a multiple of 5, so direction is clockwise. From cell 3, moving 4 clockwise lands on cell 7 (3→4→5→6→7). Unvisited, legal. Blue scores 7.

---

MOVE 3: Amber plays 2 -> cell 1
STATE 3: cell=1 visited=0,1,3,7 score Amber=4, Blue=7

*Reasoning:* Previous tile was 4 (Blue's). Sum = 4+2 = 6, not a multiple of 5, so clockwise. From cell 7, moving 2 clockwise wraps to cell 1 (7→0→1). Cell 1 is unvisited, legal. Amber scores 1, total 4.

---

MOVE 4: Blue plays 3 -> cell 6
STATE 4: cell=6 visited=0,1,3,6,7 score Amber=4, Blue=13

*Reasoning:* Previous tile was 2 (Amber's). I first checked tile 6: sum = 2+6 = 8, clockwise, landing on cell 7 — but 7 is already visited, illegal. Next I checked tile 3: sum = 2+3 = 5, a multiple of 5, so counter-clockwise. From cell 1, moving 3 counter-clockwise lands on cell 6 (1→0→7→6). Cell 6 is unvisited, legal. Since a legal move exists (tile 3), Rule 4 doesn't trigger. Blue scores 6, total 13.

---

MOVE 5: Amber plays 1 -> cell 7
STATE 5: cell=7 visited=0,1,3,6,7 score Amber=11, Blue=13

*Reasoning:* Amber's remaining tiles are {1,5}. Previous tile was 3 (Blue's). 
- Tile 1: sum = 3+1 = 4, clockwise, from cell 6 → cell 7. But 7 is already visited — illegal.
- Tile 5: sum = 3+5 = 8, clockwise, from cell 6 → cell 3 (6→7→0→1→2→3). But 3 is already visited — illegal.

Both tiles are illegal under Rule 3, so Rule 4 applies: Amber must play the smallest tile in hand (1), moving clockwise regardless of the sum calculation, and it's now permitted to land on a visited cell. From cell 6, moving 1 clockwise lands on cell 7 (already visited, but allowed under Rule 4). Amber scores 7, total 11.

---

**Final:** cell=7, visited={0,1,3,6,7}, score Amber=11, Blue=13

### Rule I'm least sure about

**Rule 4.** Two ambiguities bothered me:
1. Whether "smallest tile" should be evaluated only among the tiles that are actually illegal (which happened to be all of Amber's remaining tiles here, so it didn't matter), or unconditionally the smallest tile in hand — I assumed the latter, but the rule text is written as if Rule 4 only ever applies when *all* tiles fail anyway, so these coincide in practice.
2. Whether, once forced into Rule 4, the sum-based direction calculation from Rule 2 is meant to be entirely bypassed (as I treated it), or whether the "clockwise regardless" clause is simply confirming what the sum calculation would have given anyway in edge cases — in my playthrough it happened to match either interpretation, so I couldn't fully stress-test which reading is correct.
